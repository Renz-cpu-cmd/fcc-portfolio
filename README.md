# 💻 FreeCodeCamp Developer Portfolio

> **Responsive Developer Portfolio Showcase Page.**

[![HTML5](https://img.shields.io/badge/HTML5-Semantic-orange?logo=html5)](https://developer.mozilla.org/en-US/docs/Web/HTML)
[![CSS3](https://img.shields.io/badge/CSS3-Flexbox%20%26%20Grid-blue?logo=css3)](https://developer.mozilla.org/en-US/docs/Web/CSS)
[![FreeCodeCamp](https://img.shields.io/badge/FreeCodeCamp-Certification-green?logo=freecodecamp)](https://www.freecodecamp.org/)

**fcc-portfolio** is a sleek, responsive developer portfolio web page built as part of the FreeCodeCamp *Responsive Web Design* certification curriculum. It showcases web projects, skills, and contact links.

---

## ✨ Features

- 📱 **Fully Responsive Layout**: Built with CSS Flexbox and CSS Grid to adapt seamlessly to mobile, tablet, and desktop screens.
- 🎯 **Project Grid Section**: Visual cards showcasing web projects with interactive hover animations.
- 📬 **Contact Footer**: Direct link buttons to GitHub, social channels, and email.
- 🚀 **Zero Dependencies**: Pure HTML5 and CSS3 without external frameworks.

---

## 🚦 Quick Start

```bash
git clone https://github.com/Renz-cpu-cmd/fcc-portfolio.git
cd fcc-portfolio
# Open index.html directly in any browser
```
